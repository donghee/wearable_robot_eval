# Wearable Robot Evaluation Framework

## System Requirements

- **Operating System**: Ubuntu 22.04 or 24.04
- **Docker**: Latest version
- **VSCode**: Latest version

## Installation

Run the following command to install the complete framework:

```bash
curl -o- https://raw.githubusercontent.com/donghee/wearable_robot_eval/2025/bin/install.sh | bash
```

## Run

Run the following command to run framework and VSCode IDE

```bash
cd ~/wearable_robot_eval
./bin/run.sh
```
